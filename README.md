### 📦 [Cadastro de produtos](https://github.com/henriquecoutinho0611-lang/Projeto1-um-cadastro-de-produtos)

Projeto de cadastro simples de produtos. O repositório também reúne exercícios e aplicações em pastas separadas.

#### O aplicativo de produtos

Na pasta `App_empresa`, o programa apresenta um menu no terminal para trabalhar com os produtos.

As opções incluem:

- cadastrar um produto;
- listar os produtos salvos;
- buscar pelo nome ou pelo ID;
- editar um produto;
- apagar um produto.

Os dados do produto incluem nome, ID, largura, altura, profundidade e observações.

O programa lê e grava os registros em JSON.

Confira a [pasta do aplicativo](https://github.com/henriquecoutinho0611-lang/Projeto1-um-cadastro-de-produtos/tree/main/App_empresa) e o [menu principal em Python](https://github.com/henriquecoutinho0611-lang/Projeto1-um-cadastro-de-produtos/blob/main/App_empresa/main.py).

## 🧱 Organização dos projetos

### Aplicativo de cadastro em Python

- `main.py` mostra o menu e direciona cada opção para sua função.
- As funções de cadastro, busca, edição e remoção ficam separadas em arquivos próprios.
- A leitura e a gravação dos produtos ficam em um módulo de arquivos.
- Há funções de validação para as respostas e opções do menu.
- Os produtos são armazenados em JSON.

### Exemplos em Java

- Os projetos de alunos e produtos ficam em pastas separadas.
- O código é dividido em partes como entidade, serviço e repositório.
- Há também uma pasta dedicada aos estudos de CRUD.

Essa organização torna mais fácil abrir um projeto específico e acompanhar como ele foi montado.
